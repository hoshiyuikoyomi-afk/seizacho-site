# 星座帳の表示調整

2026-09-11の表示調整。和紙・深紅の表紙と紐・墨の星図という帳面の方向を維持して、実際のブラウザ表示を調整した。

## 帳面

紙・表紙・紙の重なり・綴じ紐の描き方を揃えた。紐の結び目は本文の高さに応じて引き伸ばさず、PCとスマホで一定の大きさを保つ。上端の赤い横線は表示しない。日記の星図は実データに基づく墨色のSVGを維持する。

## 一年の空

星座と名前をつなぐ点線は表示しない。名前は11pxのHTMLリンクとして近くの空いている場所に添え、44px以上の操作領域を保つ。夜空の霞画像・グラデーションは外し、暗色の面に実データの星と接続線を描く。

一覧と日記で同じ記録の星座が異なる形になっていたため、日記の座標・星の大きさ・結び方を共通の生成処理にまとめた。一覧はその星図を平行移動と均等な拡大だけで配置する。日記側のSVG出力・星の数・種の生成方法は変更していない。

一度導入した左右の列への並べ直しを取りやめ、元の1000×600の星図の縦横比と星座中心の配置へ戻した。各星座の表示上の拡大は、その中心の周りで1.22倍に抑える。名前同士や星座を隠さないように、名前の位置だけを調整する。記録が多い年は名前を星図の下へ並べるが、星座の中心は移動しない。記録自体の追加・改変は行わない。

## 確認範囲

ローカルChrome、PC1440×1000とスマホ幅390×844で実画面を確認。Google Fontsの実描画、既存の帳面DOMと全記録の星図SVG出力、一覧から開いた日記との星の座標・大きさ・接続線の一致、表示の重なり・欠け、名前のタップ・クリック、星座のEnter／Space、年の切替、幅の変更を確認した。hoshiとstars、星が0個・1個の記録、空の年・長い名前・件数の多い年は公開用JSONと分離した検証用データを使用した。

entries.json・koyomi.html・export seizacho.pyの内容は変更していない。エクスポートスクリプトは実行していない。紙素材の出所と制作条件はassets/README.mdに記録している。

実機スマホ・Safari・低速回線・公開向け素材圧縮は未確認。公開URLへの反映依頼後は、検証済みの変更を既存のGitHub Pages経路で公開し、配信されるファイルと実画面を確認する。公開設定や記録のエクスポート経路は変更しない。
