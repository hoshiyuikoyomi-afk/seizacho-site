# 星座帳の表示調整

2026-09-11時点の作業ブランチ。和紙・深紅の表紙と紐・墨の星図という帳面の方向を維持して、実際のブラウザ表示を調整した。

## 帳面

紙・表紙・紙の重なり・綴じ紐の描き方を揃えた。紐の結び目は本文の高さに応じて引き伸ばさず、PCとスマホで一定の大きさを保つ。上端の赤い横線は表示しない。日記の星図は実データに基づく墨色のSVGを維持する。

## 一年の空

星座と名前をつなぐ点線を削除し、星座を主役にした。名前は12pxのHTMLリンクとして各星座のすぐ下に置き、44px以上の操作領域を保つ。夜空の霞画像・グラデーションは外し、暗色の面に実データの星と接続線を描く。

星座の内部座標・接続関係・星の数・種の生成方法は変更していない。年間画面の表示では各星座全体を等倍比で拡大・移動し、大きくした星座と名前が重ならないように間隔を確保した。従来の年間画面と同じ画面上の位置ではない。スマホは左右で高さをずらして並べ、記録や名前が増えた場合は縦に表示領域を延ばす。記録自体の追加・改変は行わない。

## 確認範囲

ローカルChrome、PC1440×1000とスマホ幅390×844で実画面を確認。Google Fontsの実描画、既存の帳面DOMと生成関数、星座の内部座標、表示の重なり・欠け、名前のタップ・クリック、星座のEnter／Space、年の切替、幅の変更を確認した。hoshiとstars、空記録・長い名前・件数の多い年は公開用JSONと分離した検証用データを使用した。

entries.json・koyomi.html・export seizacho.pyの内容は変更していない。エクスポートスクリプトは実行していない。紙素材の出所と制作条件はassets/README.mdに記録している。

この記録はローカル表示の検証を示す。実機スマホ・Safari・低速回線・公開向け素材圧縮は未確認。見た目のレビューと公開判断は別であり、この作業ブランチの保存ではmainと公開設定を変更しない。
